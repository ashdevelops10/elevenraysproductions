# Hero video

Drop your high-resolution hero film here as `hero.mp4` (and optionally
`hero.webm` for smaller delivery). The site references `/videos/hero.mp4`.

Recommended:
- 1920×1080 (or 4K), H.264 / H.265, ~8–12s seamless loop
- Keep it muted and short; a poster image loads instantly as a fallback.
